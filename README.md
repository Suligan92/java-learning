# java-learning

Repository pentru exercițiile mele de învățare a limbajului Java, pe drumul către Spring Boot.

## Ce conține

- **Ziua 1:** interfețe vs. clase abstracte, polimorfism (`Shape`, `Circle`, `Rectangle`, `Triangle`)
- **În lucru:** aplicație de consolă pentru gestionarea sarcinilor (`Task`)

## Tehnologii

- Java 25
- Maven
- IntelliJ IDEA

## Cum rulezi proiectul

1. Clonează repository-ul:
   ```
   git clone https://github.com/Suligan92/java-learning.git
   ```
2. Deschide proiectul în IntelliJ IDEA.
3. Rulează clasa `Main` din `src/main/java/org/example`.
